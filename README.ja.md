# Pause & Tell｜動画解説レコーダー

[English](README.md) · [仕様](APP_SPEC.md) · [検証記録](docs/INSERTION_POC_VALIDATION.md)

**位置を選んで説明を別録りし、元動画全体へ差し込む方式**が通常の入口になります。元動画の場面を飛ばさず、説明の前後には元音声が残ります。書き出し時に再エンコードするため無劣化保存ではありません。

[現在のPRプレビューを開く](https://r1418429453-pr-1-bk-previews.ttomohisa.workers.dev/)。以前の `/insertion-poc/` も同じアプリです。モード選択は不要です。

## 使い方

1. 動画を選び、「位置」で説明したい場面へ移動します。
2. 「この位置に説明を追加」でマイクを許可し、静止画を見ながら話します。初期ツールはペン。指差し・丸・矢印、黄/白/赤、戻す・やり直す・線消去も使えます。
3. 「説明の録音を終了」。必要なら別の位置にも追加します。説明を選んで確認・削除・録り直しできます。録り直し途中の「この録音を取り消す」では元の説明が残ります。
4. 「説明を差し込んで動画を作成」→完成動画を確認→「動画を保存」。保存先から開いて再生を確認します。

位置移動は録音前の差し込み位置選択です。説明中は元動画を静止し、元動画の全区間を完成動画へ含めます。描画操作は説明時刻に沿って反映され、戻す/消す操作で過去の映像まで消えることはありません。

## 形式・安全・制限

- 標準はWebM。MP4は対応端末向けの補助選択肢で、完成30秒までの実験機能です。送付先の動画アプリで開きやすい利点がありますが、WebMを使える相手なら必須ではありません。
- 試行上限は元動画5分/250MiB、説明1区間2分、WebM完成10分。成功を保証する上限ではありません。書き出し前に長さの案内を表示します。
- ページを閉じる前に完成動画を保存してください。説明はセッション内のみで、再読み込み・終了・OSによる終了で失われます。失敗や取消では前回成功した出力を保持し、一時ファイルの削除失敗時は案内を表示して次の書き出し前に再試行します。
- 動画・音声は端末内で処理し、自動アップロードや外部CDNはありません。明示的に共有先を選んだ場合だけ完成ファイルを送ります。
- デスクトップの180秒WebM保存/全長デコードと、Pixelでの実動画録音保存・約3分末尾再生・録り直し取消を確認済み。Pixel番号/OS/ブラウザー版は未記録で、全Android/iPhone対応の保証ではありません。短いMP4の成功は別の限定的な確認です。

## 単一HTML・開発

Windowsで `build-standalone.bat` を実行します。ビルドにはNode.jsが必要です。編集元は `experiments/insertion-poc/`。ディレクトリ名は過去の名称で、別モードを意味しません。通常ビルドからルートHTML、`dist/index.html`、自己展開版 `dist/index.self-extract.html` を生成し、実行時ライブラリとライセンスを埋め込みます。

短い回帰は通常CI、長時間/native検証は節目だけ実行します。旧 `src/index.template.html` とG1〜G9の記録は以前の連続録画方式の資料です。[検証方針](docs/INSERTION_TEST_POLICY.md)を参照。PRは未マージで、本番公開は別判断です。
