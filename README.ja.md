# Pause & Tell｜動画解説レコーダー

[English README](README.md) · [正式仕様書](APP_SPEC.md) · [開発計画](DEVELOPMENT_PLAN.md)

**元動画を止めても、説明の声と完成動画の録画は進み続ける**、ブラウザだけで使う動画解説ツールです。

**現在は v0.1.0 の録画エンジン実証段階です。正式リリースではありません。** 描画ツールやスマホでの安定性は未検証です。

## v0.1.0でできること

- 再生可能なローカル動画を1本読み込む（最大**30秒／100MiB**）。
- 録画前に元動画を再生・シークで確認。録画開始時は0秒の静止状態から開始。
- 「説明を録画」を押して初めてマイク権限を要求。動画Canvasとマイク音をMediaRecorderで収録。
- **元動画だけ**再生・一時停止。停止中も出力映像とマイクは進み、元動画の終端でも説明を続けられる。
- 手動または完成録画**90秒**の上限で録画を終了。生成動画をブラウザでプレビュー。
- 名前を指定して、実際に出力されたMP4またはWebM形式で保存する。
- 日本語/英語、端末内の技術検証ログ、再録画。

**未実装:** 丸・矢印・ペン・指差しリング、元動画音声の合成、共有、タイムライン編集。開発予定は [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) に記載しています。

## 使い方

1. HTTPSまたはブラウザがマイクを許可する `file://` の配布HTMLを開きます。
2. 再生できる30秒以内の動画を選び、必要に応じて内容を確認します。
3. 「説明を録画」でマイクを許可します。元動画は停止したままです。
4. 「元動画を再生」「元動画を止める」を押して、停止中に声で説明します。完成動画の時間は止まりません。
5. 「録画を終了」でファイルを確認し、最初から最後まで再生してから保存します。

最初の試験では、元動画に音が入っていない短い動画を推奨します。現時点ではマイク音のみ録音し、元動画の音は保存しません。

## 重要な検証：G1

元動画20秒を **8秒再生 → 20秒一時停止して声で説明 → 残り12秒再生**し、完成動画が**約40秒**になり、静止区間に声が途切れず入っているかを確認します。開始前の説明時間やボタン操作分の差は計測時に区別してください。

検証記録は [docs/G1_VALIDATION.md](docs/G1_VALIDATION.md) に従います。**iPhone Safari、Android Chrome、PC Chrome/Edgeで実ファイルを確認するまではG1合格とはしません。** ビルド成功・PR Preview成功は録画の正常動作の証明ではありません。

## プライバシー

選択した動画とマイク音声はこの端末のブラウザ内だけで処理します。アプリはCDN・API・テレメトリーを実行時に要求せず、テンプレートのCSPは `connect-src 'none'` です。動画や音声を自動アップロードしません。保持する設定は言語のみです。明示的な保存以外ではファイルに書き出さず、ページを閉じると未保存データは失われます。

マイクにはブラウザの安全な接続と利用者の許可が必要です。画面ロック、別タブへの移動、着信、端末負荷やブラウザの録画実装の違いで収録が途切れる可能性があります。MP4固定ではなく、環境に応じてWebMとなることがあります。出力動画は必ずご確認ください。

## ビルド方法

このリポジトリは [htmlapps-template](https://github.com/ttomohisa/htmlapps-template) のソース・ビルド・共通コンポーネントを維持しています。編集前に `AGENTS.md` と `docs/ARCHITECTURE.md` を参照してください。

Windowsで `build-standalone.bat` を実行するとPowerShellの事前検査後、次を生成します。

- `dist/index.html`（単一HTMLの通常版）
- `dist/index.self-extract.html`（圧縮自己解凍版）
- `pause-and-tell.html`（通常版と完全一致するルートコピー）

生成物は直接編集せず、`src/index.template.html` を編集してビルドしてください。v0.1では外部ライブラリ依存なしです。
