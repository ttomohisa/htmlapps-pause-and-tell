# Pause & Tell

動画を止めて声と描画で説明し、元動画全体に差し込んで保存する、端末内処理の動画解説アプリです。

[English](README.md) · [アプリを開く](https://ttomohisa.github.io/htmlapps-pause-and-tell/)

## 主な機能

- 端末の動画を選び、好きな位置に説明を追加
- 静止画を見ながら別録りし、説明の前後に元動画の全場面と元音声を保持
- 指差し・丸・矢印・ペン、3色、戻す・やり直す・線消去
- 説明ごとの確認・削除・安全な録り直し
- WebM動画の作成と、対応端末での補助的なMP4出力
- 録音・動画作成・保存を分離し、保存名の編集と端末共有に対応
- 処理の中止、書き出し失敗時の前回成功結果の保持
- 小さな録音経過表示と上限接近時の警告
- 日本語/英語、キーボード操作、PC・スマートフォン対応レイアウト

## 使い方

1. [アプリを開き](https://ttomohisa.github.io/htmlapps-pause-and-tell/)、動画を選び、「位置」で説明したい場面へ移動します。
2. 「この位置に説明を追加」でマイクを許可し、静止画を見ながら話します。ペン・指差し・丸・矢印で描き込めます。
3. 「説明の録音を終了」。必要なら別の位置にも追加します。説明を選んで確認・削除・録り直しできます。録り直し途中の「この録音を取り消す」では元の説明が残ります。
4. 「説明を差し込んで動画を作成」→完成動画を確認→「動画を保存」。保存先から開いて再生を確認します。「共有」は対応端末だけに表示されます。

位置移動は録音前の差し込み位置選択です。説明中は元動画を静止します。描画操作は説明時刻に沿って反映され、戻す/消す操作で過去の映像まで消えることはありません。書き出し時に再エンコードするため無劣化保存ではありません。

## プライバシー

動画・音声・描画はブラウザー内で処理します。自動アップロード、実行時のCDN取得、アクセス解析、サーバー処理はありません。Web版では最初にHTMLを取得します。端末の共有機能で送付先を選んだ場合だけ、完成ファイルをその相手へ送ります。

説明はセッション内のみです。再読み込み・ページ終了・OSによる終了で失われる場合があります。離れる前に必要な完成動画を保存してください。セッション内での録り直しや書き出しの失敗・取消では前回の説明/成功結果を保持します。一時ファイルの削除失敗は表示し、次の書き出し前に再試行します。プロジェクトの永続保存・復元機能ではありません。

## 対応ブラウザーと制限

v1.0.0は差し込み方式の確認済み範囲を引き継ぐ版で、全端末への対応保証ではありません。録音にはマイク権限とMediaRecorder、動画作成には対応デコーダー/エンコーダーとWebCodecsが必要です。ローカルHTMLでマイクを利用できない場合はHTTPSのWeb版を使ってください。

- 標準は **WebM VP8/Opus**。**MP4 AVC/AACは補助的な実験機能**で、**完成30秒まで**です。送付先の動画アプリで開きやすい利点がありますが、WebMを使える相手なら必須ではありません。
- 試行上限は元動画 **5分/250MiB**、説明1区間 **2分**、WebM完成 **10分**。処理成功や端末メモリーの保証値ではありません。書き出し前に長さの案内を表示します。
- デスクトップの180秒WebM保存/全長デコードと、Pixelでの実動画録音保存・約3分末尾再生・録り直し取消を確認済み。Pixel番号/OS/ブラウザー版は未記録です。短いMP4の成功は別の限定的な確認です。
- 全Android/iPhone、任意のカメラ動画のVFR/HEVC/HDR、上限いっぱいの入出力、実端末の容量不足、OS終了後の復旧は未確認です。未対応コーデックはエラーで案内します。

詳しい測定環境・結果は[検証記録](docs/INSERTION_POC_VALIDATION.md)を参照してください。追加のAAC/WASM代替エンコーダーは同梱していません。

## オフライン単一HTML

保存した `pause-and-tell.html` または `dist/index.html` を開いて使います。通常ビルドでは同一内容のこれらのHTMLと、小さい自己展開版 `dist/index.self-extract.html` を生成します。実行時ライブラリ・ライセンス・ソース案内を埋め込み、保存後はサーバー不要です。自己展開版は追加で `DecompressionStream` が必要です。マイクとコーデックの対応はブラウザーに依存します。

[通常HTML](https://ttomohisa.github.io/htmlapps-pause-and-tell/index.html)と[自己展開HTML](https://ttomohisa.github.io/htmlapps-pause-and-tell/index.self-extract.html)を保存してオフラインで使えます。Web版はマージ済みmainの内容です。

## 開発

[AGENTS.md](AGENTS.md)と[仕様](APP_SPEC.md)を参照してください。Node.jsを導入したWindowsで `build-standalone.bat` を実行します。PowerShellの `./scripts/check-repository.ps1` ではビルドと両配布版の検証を行います。

編集元は `experiments/insertion-poc/`。過去のディレクトリ名で、別アプリを意味しません。固定した依存関係はこの中の `package.json` とnpm lockに記録します。生成HTMLを直接編集しないでください。旧 `src/index.template.html` とG1〜G9の記録は以前の連続録画方式の資料です。

短い回帰は通常CI、長時間/native検証は節目だけ実行します。[検証方針](docs/INSERTION_TEST_POLICY.md)を参照。既存のGitHub Pages配信はmain更新後に再ビルド・検証して公開します。
