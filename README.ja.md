# Pause & Tell｜動画解説レコーダー

[English README](README.md) · [正式仕様書](APP_SPEC.md) · [開発計画](DEVELOPMENT_PLAN.md)

**元動画を止めても、説明の声と完成動画の録画は進み続ける**、ブラウザだけで使う動画解説ツールです。

**現在は v0.4.0 のスマホ操作・指差し機能の試作段階です。正式リリースではありません。** iPhone・Android実機の録画・指操作・保存の安定性は未検証です。

## v0.4.0でできること

- **指差しリング**を追加しました。「指差し」を選び動画上を1回タップすると、輪と中央の点が表示されます。動画再生中なら元動画だけ停止します。
- 指差し・丸・矢印・ペンの4ツールをスマホでは動画の直前へ配置し、指で選びやすいタップ領域を確保しました。指差しが初期選択です。
- スマホの下部固定操作は、録画前は「説明を録画」「元動画を再生」、録画中は「再生/停止」「録画を終了」に切り替えます。安全領域と下部余白を設けます。動画読込後は描画と動画の場所へ、録画終了後は完成プレビューへ自動移動します。縦動画や高さが低い横向き画面では、下部操作バーに隠れない位置へ動画全体を移動します。
- リングは現在表示中の描画として保持し、**1つ戻す・線を消す・元動画の再生**で消えます。過去に録画されたフレームは書き換わりません。
- 動画上に録画中の再生状態を示します（完成動画には表示されません）。
- [G4検証手順](docs/G4_VALIDATION.md) を追加しました。実機での録音・保存・指操作は未確認です。


- **丸（楕円）・矢印・フリーペン**で動画に線を描けます。色は黄・白・赤の3色。暗い映像でも線が見やすいよう縁取りを入れます。
- 再生中に描き始めると**元動画だけ一時停止**し、マイクと完成動画の録画は続きます。
- 描画位置は縦動画・横動画どちらでも正規化座標で保存し、録画対象Canvasに直接合成します。操作ボタンは映像に含みません。
- 「1つ戻す」「線を消す」は現在表示されている線にだけ効き、**録画済みの声や線は変わりません**。再生時・録画開始時・再録画時にも現在の線は消えます。
- 指・マウス・ペンで描けます。iOS Safari / Android Chrome実機での録画と描画は引き続き検証が必要です。

- **動画を選ぶ → 説明を録る → 動画を保存**の3段階を表示し、読み込み中や選択済みファイル情報も示します。
- マイクの使用理由を録画前に表示し、録画の中断が発生した場合は結果の確認を促します。
- 言語切り替えは **JA / EN** 表示。ヘルプを開いている間は背後をスクロールできず、閉じると元の位置に戻ります。スマホではフッターを非表示にします。
- 提供されたSVGをfaviconとヘッダーアイコンの共通ソースに採用し、**完全ローカル処理**の表示に変更しました。

- 再生可能なローカル動画を1本読み込む（最大**30秒／100MiB**）。
- 録画前に元動画を再生・シークで確認。録画開始時は0秒の静止状態から開始。
- 「説明を録画」を押して初めてマイク権限を要求。動画Canvasとマイク音をMediaRecorderで収録。
- **元動画だけ**再生・一時停止。停止中も出力映像とマイクは進み、元動画の終端でも説明を続けられる。
- 手動または完成録画**90秒**の上限で録画を終了。生成動画をブラウザでプレビュー。
- 名前を指定して、実際に出力されたMP4またはWebM形式で保存する。
- 日本語/英語、端末内の技術検証ログ、再録画。

**未実装:** 元動画音声の合成、共有、タイムライン編集。開発予定は [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) に記載しています。

## 使い方

1. HTTPSまたはブラウザがマイクを許可する `file://` の配布HTMLを開きます。
2. 再生できる30秒以内の動画を選び、必要に応じて内容を確認します。
3. 「説明を録画」でマイクを許可します。元動画は停止したままです。
4. 「元動画を再生」「元動画を止める」を押して、停止中に声で説明します。完成動画の時間は止まりません。
5. 「録画を終了」でファイルを確認し、最初から最後まで再生してから保存します。

録画中は「指差し」で動画上を1回タップするとリングが付きます。丸・矢印・ペンは動画上をなぞって描けます。線を描き始めると元動画だけが止まり、線は再生時に自動で消えます。最初の試験では、元動画に音が入っていない短い動画を推奨します。現時点ではマイク音のみ録音し、元動画の音は保存しません。

## 重要な検証：G1

元動画20秒を **8秒再生 → 20秒一時停止して声で説明 → 残り12秒再生**し、完成動画が**約40秒**になり、静止区間に声が途切れず入っているかを確認します。開始前の説明時間やボタン操作分の差は計測時に区別してください。

検証記録は [docs/G1_VALIDATION.md](docs/G1_VALIDATION.md) に従います。**iPhone Safari、Android Chrome、PC Chrome/Edgeで実ファイルを確認するまではG1合格とはしません。** v0.4.0の画面・状態管理は先行実装ですが、G1/G2/G3/G4の最終合格を意味しません。操作面の確認は [G2検証手順](docs/G2_VALIDATION.md) を参照してください。 ビルド成功・PR Preview成功は録画の正常動作の証明ではありません。

## プライバシー

選択した動画とマイク音声はこの端末のブラウザ内だけで処理します。アプリはCDN・API・テレメトリーを実行時に要求せず、テンプレートのCSPは `connect-src 'none'` です。動画や音声を自動アップロードしません。保持する設定は言語のみです。明示的な保存以外ではファイルに書き出さず、ページを閉じると未保存データは失われます。

マイクにはブラウザの安全な接続と利用者の許可が必要です。画面ロック、別タブへの移動、着信、端末負荷やブラウザの録画実装の違いで収録が途切れる可能性があります。MP4固定ではなく、環境に応じてWebMとなることがあります。出力動画は必ずご確認ください。

## ビルド方法

このリポジトリは [htmlapps-template](https://github.com/ttomohisa/htmlapps-template) のソース・ビルド・共通コンポーネントを維持しています。編集前に `AGENTS.md` と `docs/ARCHITECTURE.md` を参照してください。

Windowsで `build-standalone.bat` を実行するとPowerShellの事前検査後、次を生成します。

- `dist/index.html`（単一HTMLの通常版）
- `dist/index.self-extract.html`（圧縮自己解凍版）
- `pause-and-tell.html`（通常版と完全一致するルートコピー）

生成物は直接編集せず、`src/index.template.html` を編集してビルドしてください。v0.4.0では外部ライブラリ依存なしです。
