# Pause & Tell｜動画解説レコーダー

[English README](README.md) · [正式仕様書](APP_SPEC.md) · [開発計画](DEVELOPMENT_PLAN.md)

**元動画を止めても、説明の声と完成動画の録画は進み続ける**、ブラウザだけで使う動画解説ツールです。

**現在は v0.7.0 の保存・共有・ヘルプの検証段階です。正式リリースではありません。** iPhone・Android実機の録画・指操作・保存の安定性は未検証です。

## v0.7.0でできること

- **録画結果を再生して確認 → 名前を付ける → 動画を保存**の導線を見直しました。保存形式は実際に生成できたMP4またはWebMです。
- ファイル名の禁則文字・危険な制御文字・余計な動画拡張子を整理し、空の場合は `pause-and-tell` に戻します。
- 端末が**ファイル共有に対応すると確認できる場合のみ**「動画を共有」を表示します。回収データ・再生が確認できないファイルには共有を出しません。
- **保存ボタンを押しただけでは保存完了を判定できません。** 保存・共有を試した後も結果を保持し、再録画や元動画差し替えでは必ず破棄確認をします。
- 共有をキャンセルしても結果は消えず、共有に失敗しても通常のダウンロードが可能です。共有は利用者が選んだアプリ・相手へOS経由でファイルが渡るため、送信の可能性があります。
- 日英の説明・保存状態を整理し、[G7検証手順](docs/G7_VALIDATION.md) を追加しました。iPhone・Android実機の保存・共有成功はまだ未確認です。



- 録画終了の応答がなくても、**9秒後に処理を打ち切り**、受信済みの録画データを可能な範囲で回収します。
- マイクの切断・3.2秒以上の無音化、録画映像トラック停止、元動画の読み込みエラー、タブ非表示を検知して途中終了・回収を試みます。
- 正常な録画と、**途中までしか回収できなかった録画／再生を確認できなかったデータ**を別表示にします。破損の可能性があるものを正常完了とは表示しません。
- 元動画30秒・100MiB、録画90秒という試作版の上限を維持し、録画データが96MiBを超えた場合も安全のため停止します。目標上限への拡大は実機検証後です。
- 同じ動画での連続再録画・マイク権限拒否・ファイル差し替えの状態管理を見直しました。実機での安定性はまだ確認が必要です。
- 模擬マイクを使ったChromiumの**実時間90秒録画試験**では、20秒で元動画が終了した後も録画が続き、90秒で正常終了。保存したVP8/Opusの動画・音声パケットは約90秒まで存在しました。iPhone・Android実機の保証ではありません。
- 詳しい回復フローと試験項目は [G6検証手順](docs/G6_VALIDATION.md) に記載しています。



- **初期設定の「説明音声のみ」は維持**しています。選ばない限り元動画の音は録音しません。
- 「音声の設定」を開くと、**PC版Chromiumでのみ**「元動画の音＋説明音声（試験用）」を選択できます。スマホ・Safari・Firefoxでは未検証のため無効です。
- 元動画の音量は15％／**30％（既定）**／50％を選択でき、マイクは100％です。元動画の一時停止中は元音声も止まり、説明音声は録り続けます。
- 元動画音声はスピーカーへ再生せず、録画用音声にだけ合成します。音声経路を準備できない場合はエラーを表示し、勝手に説明音声のみへ切り替えません。
- **試験機能は正式対応を意味しません。** 出力ファイルの音量・同期・再生を検証するG5手順を [こちら](docs/G5_VALIDATION.md) に追加しました。iPhone・Androidの実機受け入れは引き続き未完了です。



- **指差しリング**を追加しました。「指差し」を選び動画上を1回タップすると、輪と中央の点が表示されます。動画再生中なら元動画だけ停止します。
- 指差し・丸・矢印・ペンの4ツールをスマホでは動画の直前へ配置し、指で選びやすいタップ領域を確保しました。指差しが初期選択です。
- スマホの下部固定操作は、録画前は「説明を録画」「元動画を再生」、録画中は「再生/停止」「録画を終了」に切り替えます。安全領域と下部余白を設けます。動画読込後は描画と動画の場所へ、録画終了後は完成プレビューへ自動移動します。縦動画や高さが低い横向き画面では、下部操作バーに隠れない位置へ動画全体を移動します。
- リングは現在表示中の描画として保持し、**1つ戻す・線を消す・元動画の再生**で消えます。過去に録画されたフレームは書き換わりません。
- 動画上に録画中の再生状態を示します（完成動画には表示されません）。
- [G4検証手順](docs/G4_VALIDATION.md) を追加しました。実機での録音・保存・指操作は未確認です。


- **丸（楕円）・矢印・フリーペン**で動画に線を描けます。色は黄・白・赤の3色。暗い映像でも線が見やすいよう縁取りを入れます。
- 再生中に描き始めると**元動画だけ一時停止**し、マイクと完成動画の録画は続きます。
- 描画位置は縦動画・横動画どちらでも正規化座標で保存し、録画対象Canvasに直接合成します。操作ボタンは映像に含みません。
- 「1つ戻す」「線を消す」は現在表示されている線にだけ効き、**録画済みの声や線は変わりません**。再生時・録画開始時・再録画時にも現在の線は消えます。
- 指・マウス・ペンで描けます。iOS Safari / Android Chrome実機での録画と描画は引き続き検証が必要です。

- **動画を選ぶ → 説明を録る → 動画を保存**の3段階を表示し、読み込み中や選択済みファイル情報も示します。
- マイクの使用理由を録画前に表示し、録画の中断が発生した場合は結果の確認を促します。
- 言語切り替えは **JA / EN** 表示。ヘルプを開いている間は背後をスクロールできず、閉じると元の位置に戻ります。スマホではフッターを非表示にします。
- 提供されたSVGをfaviconとヘッダーアイコンの共通ソースに採用し、**完全ローカル処理**の表示に変更しました。

- 再生可能なローカル動画を1本読み込む（最大**30秒／100MiB**）。
- 録画前に元動画を再生・シークで確認。録画開始時は0秒の静止状態から開始。
- 「説明を録画」を押して初めてマイク権限を要求。動画Canvasとマイク音をMediaRecorderで収録。
- **元動画だけ**再生・一時停止。停止中も出力映像とマイクは進み、元動画の終端でも説明を続けられる。
- 手動または完成録画**90秒**の上限で録画を終了。生成動画をブラウザでプレビュー。
- 名前を指定して、実際に出力されたMP4またはWebM形式で保存する。
- 日本語/英語、端末内の技術検証ログ、再録画。

**未対応・未検証:** 元動画音声の合成はPC版Chromium向けの試験機能です。一般公開の対応保証はありません。共有・タイムライン編集は未実装です。開発予定は [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) に記載しています。

## 使い方

1. HTTPSまたはブラウザがマイクを許可する `file://` の配布HTMLを開きます。
2. 再生できる30秒以内の動画を選び、必要に応じて内容を確認します。
3. 「説明を録画」でマイクを許可します。元動画は停止したままです。
4. 「元動画を再生」「元動画を止める」を押して、停止中に声で説明します。完成動画の時間は止まりません。
5. 「録画を終了」でファイルを確認し、最初から最後まで再生してから保存します。

録画中は「指差し」で動画上を1回タップするとリングが付きます。丸・矢印・ペンは動画上をなぞって描けます。線を描き始めると元動画だけが止まり、線は再生時に自動で消えます。最初の試験では、元動画に音が入っていない短い動画を推奨します。既定ではマイク音のみ録音します。対応するPCでは試験用の音声合成を選択できますが、完成ファイルの音量・同期を必ず確認してください。

## 重要な検証：G1

元動画20秒を **8秒再生 → 20秒一時停止して声で説明 → 残り12秒再生**し、完成動画が**約40秒**になり、静止区間に声が途切れず入っているかを確認します。開始前の説明時間やボタン操作分の差は計測時に区別してください。

検証記録は [docs/G1_VALIDATION.md](docs/G1_VALIDATION.md) に従います。**iPhone Safari、Android Chrome、PC Chrome/Edgeで実ファイルを確認するまではG1合格とはしません。** v0.7.0の画面・状態管理は先行実装ですが、G1/G2/G3/G4/G5/G6/G7の最終合格を意味しません。操作面の確認は [G2検証手順](docs/G2_VALIDATION.md) を参照してください。 ビルド成功・PR Preview成功は録画の正常動作の証明ではありません。

**G5の自動試験結果（実機対応の保証ではありません）：** 模擬マイク880Hzと元動画440Hzを使い、保存したWebMから、再生中は両方・元動画停止中は模擬マイクのみ・再開後は再び両方の音が入ることを測定しました。繰り返し録画と元動画の差し替えも成功しています。iPhone/Androidの実機録音・他アプリ再生は未検証です。[G5検証記録](docs/G5_VALIDATION.md)を参照してください。

### 録画が中断された場合

録画の途中で問題が起きた場合は、受信済みのデータを回収できるか試みます。再生可能な部分があるときは注意書きを付けて表示し、再生確認ができないデータでも破損の可能性を示して手元に保存できます。**正常な動画を作成できたという意味ではありません。** ブラウザの強制終了・端末の電源断・画面ロックなどから必ず復旧できるわけではありません。保存後も音声・映像を最後まで確認してください。

### 保存と共有について

「動画を保存」はブラウザへのダウンロード依頼です。実際に端末へ保存されたことをアプリ側で確定できないため、ダウンロード一覧・ファイル管理アプリでご確認ください。「動画を共有」はファイル共有に対応する端末でのみ表示され、**押して共有先を選ぶと、その相手やアプリへデータが送られる可能性があります**。アプリ自体は元動画やマイク音声を自動送信しません。共有をキャンセルしても結果はそのまま残り、再保存できます。

## プライバシー

選択した動画とマイク音声はこの端末のブラウザ内だけで処理します。アプリはCDN・API・テレメトリーを実行時に要求せず、テンプレートのCSPは `connect-src 'none'` です。動画や音声を自動アップロードしません。保持する設定は言語のみです。明示的な保存以外ではファイルに書き出さず、ページを閉じると未保存データは失われます。

マイクにはブラウザの安全な接続と利用者の許可が必要です。画面ロック、別タブへの移動、着信、端末負荷やブラウザの録画実装の違いで収録が途切れる可能性があります。MP4固定ではなく、環境に応じてWebMとなることがあります。出力動画は必ずご確認ください。

## ビルド方法

このリポジトリは [htmlapps-template](https://github.com/ttomohisa/htmlapps-template) のソース・ビルド・共通コンポーネントを維持しています。編集前に `AGENTS.md` と `docs/ARCHITECTURE.md` を参照してください。

Windowsで `build-standalone.bat` を実行するとPowerShellの事前検査後、次を生成します。

- `dist/index.html`（単一HTMLの通常版）
- `dist/index.self-extract.html`（圧縮自己解凍版）
- `pause-and-tell.html`（通常版と完全一致するルートコピー）

生成物は直接編集せず、`src/index.template.html` を編集してビルドしてください。v0.7.0では外部ライブラリ依存なしです。
