# Pause & Tell｜動画解説レコーダー

[English](README.md) · [仕様書](APP_SPEC.md) · [開発計画](DEVELOPMENT_PLAN.md)

**動画を一時停止して、その場を指差したり線を描いたりしながら声で説明する**ブラウザツールです。完成動画には元動画・描画・説明音声が含まれます。元動画の停止中も録画とマイク収録は続きます。

> **v0.9.1 開発中（Draft PR）**：iPhone Safari／Android Chromeの実機録画・保存・別アプリ再生は未検証です。公開判定は保留しています。

## 使い方

1. 元動画を選びます。
2. 動画の上に並ぶ「指差し・丸・矢印・ペン」から描画ツールを選びます。
3. 動画のすぐ下の **「録画して再生」** でマイクを許可します。録画が始まると元動画も再生されます。先頭で停止したまま説明したい場合は「最初の画面を停止したまま説明する」をチェックします。
4. 必要な場所で **「元動画を一時停止」** して説明・描画します。再生すると現在の描画は消えます。過去に録画した描画と音声は変更されません。
5. **「録画を終了」** を押し、完成動画を最後まで確認してから保存します。

描画は **Ctrl+Z / ⌘Z で戻す、Ctrl+Y / Ctrl+Shift+Z / ⌘Shift+Z でやり直す** ことができます。「線を消す」も同じ停止画面内なら取り消せます。文字入力欄では通常の編集ショートカットが優先されます。

## 保存とプライバシー

入力した動画とマイク音声はブラウザ内で処理します。自動アップロード・CDN・利用分析の送信は行いません。対応端末で明示的に「動画を共有」して共有先を選んだ場合のみ、完成ファイルがその先へ送信されることがあります。

保存形式はブラウザが実際に作成した **MP4またはWebM** です。ダウンロード開始だけでは端末への保存完了を保証できません。保存先を確認してください。中断録画は注意書きを付けて回収可能なデータのみ保存できます。

## 現在の制限

| 項目 | 暫定値 |
| --- | --- |
| 元動画の長さ | 最大30秒 |
| 元動画のファイルサイズ | 最大100MiB |
| 完成録画時間 | 最大90秒 |

この値はブラウザの絶対的な限界ではなく、**録画・動画デコード時のメモリ消費を実機で検証するために設けた暫定上限**です。正式な上限はスマートフォン実機で確認したうえで変更します。録画バッファにも安全上限があります。

元動画の音声は既定で含めません（マイク音声のみ）。PC版Chromiumでは元動画音声との合成を試験的に選べますが、実機での安定動作は未保証です。マイク権限拒否・画面ロック・別タブ移動によって録画が失敗する場合があります。

## 単一HTML・開発

配布用の `dist/index.html` と圧縮自己展開版 `dist/index.self-extract.html` を生成し、実行時は外部ライブラリに依存しません。編集は `src/index.template.html`、Windowsでのビルドは `build-standalone.bat` を使用します。通常画面に技術検証ログは表示しません。開発時だけURLに `?debug=1` を付けると確認できます。
