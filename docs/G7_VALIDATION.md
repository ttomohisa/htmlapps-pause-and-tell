# G7 — Review, download and native file sharing (v0.7.0)

> **Status: implemented as a Draft PR, but G7 physical-device gate is PENDING.** The exported file must be tested in actual iPhone Safari and Android Chrome; Chromium automation cannot prove that the OS completed a download or that a recipient got a shared file.

## Product boundary

- A playable **result** has a local video preview, format/size/elapsed information, editable filename, **Download video** and **Record again**.
- A **recovery** output remains separate, with a corruption/interruption warning. It may be saved as a partial WebM/MP4 or raw `.bin`, but must **never** be offered via native Share.
- The same output Blob stays in memory when Download is clicked, native Share is canceled, or Share fails. No new rendering, upload or remote dependency is needed.
- **Download** uses a user-clicked `blob:` URL + HTML `a.download` with a normalized name and actual extension. JavaScript **cannot know whether the OS successfully saved it**. The message says that download was *requested*, never that the user definitely saved the file.
- **Share** is offered *only* for a verified playable `video/mp4` or `video/webm` when `navigator.share()` and `navigator.canShare({files:[File]})` are available and the browser is a secure context. Build a File from the local Blob; call `navigator.share({files})` **directly from the click without awaiting anything first** (transient user activation).
- Native file sharing can send data outside the device **only after the user explicitly selects a share destination**. No external transmission is initiated automatically by the app. A resolved `navigator.share()` Promise may merely mean the native share UI opened; the app cannot guarantee recipient delivery.
- On `AbortError` (cancel), keep the result without a failure toast. On another exception, show a localized explanation and keep Download available.
- The app cannot verify disk writes or delivery, so both **Record again** and **Change video** require a discard confirmation whenever an output exists, even after Download or Share was requested. Leaving the page warns similarly; the browser may suppress the `beforeunload` prompt.
- Filename: editable stem; sanitize slash/backslash, reserved characters, control and bidi override characters; strip known video extensions, trim trailing space/dot, cap at 120 characters and fallback to `pause-and-tell`; preserve MIME/container extension and use it in both File-share metadata and the download.
- Preserve JA/EN, source drawing, experimental audio mode, Help background scroll lock, local diagnostics, identical template favicon, and `connect-src 'none'` CSP.

## Gate

Automated browser tests may check output filename, native share capability gating, simulated share outcomes, no JS/network errors and retained Blob/URL behavior. These **cannot** certify native OS filesystem save/share, user permissions, or hardware microphone continuity. G7 remains **PENDING** until the physical-device matrix is completed; G1–G6 physical tests are also still open.
