使い方と注意事項

      
    

    


      
      
使い方

      
    
        
  1. 30秒以内・100MiB以内の再生できる動画を選びます。
    2. 
        
  2. マイクを許可して録画を開始します。録画開始時、元動画は停止しています。
    3. 
        
  3. 元動画を再生・一時停止しながら説明します。元動画の停止中もマイクと完成動画の録画は続きます。
    4. 
        
  4. 丸・矢印・ペンで注目箇所を描きます。描画開始で元動画だけ停止します。線は再生時に消えます。
    5. 
        
  5. 「録画を終了」で結果を作り、再生してから保存します。
    6. 
      

      
プライバシー

      
選択動画とマイク音声は端末のブラウザ内で処理します。外部API・クラウドへアップロードしません。言語設定以外は端末内に永続保存しません。

      
技術試作版の注意

      
    
        
  • 「1つ戻す」「線を消す」は現在の表示だけに効きます。すでに録画された声・線・映像は取り消せません。
    • 
        
  • 音声はマイクのみを録ります。元動画の音声は含まれません。
    • 
        
  • ブラウザによって出力はMP4またはWebMです。録画中の画面ロック・タブ移動・着信では失敗する可能性があります。
    • 
        
  • ファイルはメモリ上に保持され、ページを閉じると未保存の録画は失われます。結果を最後まで再生して確認してください。
    • 
      

      
このアプリは実行時の外部通信なしで動くことを目指しています。マイクはブラウザの安全なコンテキストと許可が必要です。file:// と HTTPS は別々に検証します。
